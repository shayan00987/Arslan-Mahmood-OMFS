# Dr. Arslan Mahmood — OMFS Website

A responsive, animated static front-end concept built with plain HTML, CSS, and JavaScript.

## Run locally
Open `index.html` in a modern browser. No build step or external dependencies are required.

## Included
- `index.html` — page structure and content
- `styles.css` — responsive styling, transitions, reveal animations, mobile navigation
- `script.js` — mobile menu, reveal-on-scroll, FAQ accordion, form validation and WhatsApp handoff
- `images/` — five original AI-generated visual assets created for this website

## Before publishing
This is a front-end concept, not a verified medical practice website. Confirm the doctor's qualifications, services, clinic address, contact number, appointment URL, privacy notice, and all claims before deployment. The appointment form opens WhatsApp and requires the correct phone number to be configured in `script.js`. No form data is sent to a server. The image assets are AI-generated concept imagery and should not be represented as actual clinical photographs or actual patient outcomes.
